#  Online Shopping Cart

##  Project Overview

The **Online Shopping Cart** is a simple Java-based console application that simulates an online shopping experience. Users can view available products, select items, add them to their shopping cart, and calculate the total bill.

This project was developed to practice **Java programming and Object-Oriented Programming concepts**.

##  Features

*  Display available products
*  Add products to the shopping cart
*  Select product quantities
*  Calculate the total bill
*  Display the final amount
*  Simple console-based interface

##  Technologies Used

* **Java**
* **Scanner Class**
* **Arrays / Variables**
* **Conditional Statements**
* **Loops**
* **Object-Oriented Programming Concepts**

##  How to Run

### 1. Install Java

Make sure **JDK** is installed on your computer.

### 2. Clone the Repository

```bash
git clone https://github.com/Ranjani-P11/OnlineShoppingCart.git
```

### 3. Open the Project

Open the project folder in **VS Code**, **Eclipse**, **IntelliJ IDEA**, or any Java-supported IDE.

### 4. Compile the Program

```bash
javac OnlineShoppingCart.java
```

### 5. Run the Program

```bash
java OnlineShoppingCart
```
